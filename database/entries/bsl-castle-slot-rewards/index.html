Better Structure Loot / 小さな機能

無限城の宝箱抽選

通常16〜20枠、Elite19〜23枠、宝物庫23〜27枠。

コード上の設定を確認 / ゲーム内動作は未確認

どんなもの？

抽選した数の枠をランダムに選び、各枠に同じ重み付き報酬テーブルから1回ずつ報酬を入れます。同じアイテムが別の枠に出ることもあります。

使い方

無限城の戦闘を終え、宝箱の封印を解除します。

入手方法・利用条件

新しく生成される無限城報酬に適用します。

確認できた設定

以下はコードに設定された値です。本番の効果・表示を検証した結果ではありません。

  • 腐肉・キノコ・パンケーキ・金などを基本報酬に、部屋別の素材・ポーション・進行素材を抽選します。
  • 配布済みの箱は再抽選・再補充しません。
  • 実機の報酬表示とポーション出力は引き続き確認対象です。
