出口の帰還陣

出口を見つけたら、中心でしゃがんで帰還。

コード上の設定を確認 / ゲーム内動作は未確認

どんなもの？

出口の部屋へ入ると、その出口を再構成で動かさない状態にします。中心の帰還陣で30tickしゃがみ続けると、保存された個人の帰還地点へ戻る処理です。20 TPSなら約1.5秒が目安です。

使い方

「しゃがむと帰還」の表示が出る位置でしゃがみ続けます。しゃがみを解除したり、範囲から外れたりすると待機を取り消します。

入手方法・利用条件

無限城内の探索で扱う機能です。入口の場所や参加条件は公開案内を準備中です。

確認できた設定

以下はコードに設定された値です。本番の効果・表示を検証した結果ではありません。

  • 入口の位置・参加手順は公開案内を準備中です。
  • 全参加者が正常に帰還した場合に、次の探索用の城を作り直す流れになります。
  • 死亡やログアウトだけでは、正常帰還と同じ扱いで探索を終了しません。
