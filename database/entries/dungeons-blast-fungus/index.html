Minecraft Dungeons / アイテム・ブロック

ブラスト茸

爆発するキノコを5発放つ道具。

コード上の設定を確認 / ゲーム内動作は未確認

どんなもの？

視線方向へ、少しずつ向きの違うキノコの弾を5発続けて放ちます。着弾点から4ブロック以内の有効な対象へ爆発ダメージを与え、命中成功時に吐き気を付与する処理です。

使い方

手に持って使用します。再使用までの待ち時間や、対象・必要ソウルの条件を確認してください。

入手方法・利用条件

作業台で通常版を製作するレシピがあります。関連レシピで材料の個数・配置・完成数を確認できます。

  • ブラスト茸のレシピ →

確認できた設定

以下はコードに設定された値です。本番の効果・表示を検証した結果ではありません。

  • 爆発ダメージ処理に渡す基礎値は11。吐き気の設定は100ティック（5秒）です。
  • 基本クールダウン：9秒。装備やトーテムの補正は別です。
  • 説明は現在のコードにある処理を照合したものです。ゲーム内での操作・効果・入手の実証は未完了です。
