Mycology / 小さな機能

キノコの発見記録

集めた種類を、自分だけの図鑑に記録。

コード上の設定を確認 / ゲーム内動作は未確認

どんなもの？

鑑定で見つけた種類をプレイヤーごとに保存します。発見済みの項目は名前とレア度を表示し、未発見の項目は伏せる構成です。図鑑の本を別の人に渡しても、記録を本で受け渡す仕組みではありません。

使い方

実際の画面操作と本番での利用状況は未確認です。

入手方法・利用条件

Mycologyに含まれる機能です。鑑定士に会える場所は確認中です。

確認できた設定

以下はコードに設定された値です。本番の効果・表示を検証した結果ではありません。

  • 赤色15種・茶色20種・深紅50種・歪んだ50種の合計135種。
  • 一覧は10種ずつ。未発見の名前と画像は伏せられます。
  • Webの一覧はゲーム内の個人の発見状況とは連動していません。

ここで紹介する効果・使い方はゲーム内の設定です。現実のキノコの食用判断には使えません。
