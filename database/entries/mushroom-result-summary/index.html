Mycology / 小さな機能

鑑定結果と次のスタック

最高レア・NEW・発見数の変化をまとめて確認。

コード上の設定を確認 / ゲーム内動作は未確認

どんなもの？

結果画面には今回の最高レア、新規発見の種類数、鑑定前後の図鑑の発見数が表示されます。内訳はレア度の高い種類から並び、新しく見つけたものにはNEWが付きます。

使い方

結果画面からキノコ図鑑を開くか、同じ色の次のスタックを鑑定するボタンへ進みます。

入手方法・利用条件

Mycologyの鑑定士メニューで利用する機能です。鑑定士の所在は公開案内を準備中です。

確認できた設定

以下はコードに設定された値です。本番の効果・表示を検証した結果ではありません。

  • 64個の鑑定ではMAX STACKと表示します。
  • 次に鑑定する数は、演出後に持ち物を確認した最初の該当スタックの個数です。別スロットを合算しません。
  • 次のスタックがない場合は鑑定メニューへ戻るボタンになります。
  • 持ち物に入りきらなかった分がある場合は、足元へ置いた数を結果に表示します。

ここで紹介する効果・使い方はゲーム内の設定です。現実のキノコの食用判断には使えません。
