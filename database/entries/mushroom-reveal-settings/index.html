Mycology / 小さな機能

演出の長さとサウンド設定

じっくり・短縮・OFFを、自分のペースで選ぶ。

コード上の設定を確認 / ゲーム内動作は未確認

どんなもの？

鑑定士メニューには演出の長さとサウンドを別々に切り替えるボタンがあります。設定はプレイヤーごとに保存されます。

使い方

「演出」を押すと、じっくり → 短縮 → OFFの順に切り替わります。「サウンド」でON/OFFを変更します。

入手方法・利用条件

Mycologyの鑑定士メニューで利用する機能です。鑑定士の所在は公開案内を準備中です。

確認できた設定

以下はコードに設定された値です。本番の効果・表示を検証した結果ではありません。

  • 初期設定は「じっくり」、サウンドONです。
  • 鑑定音は鑑定した本人に再生する処理です。
  • OFFでは演出と演出音を省き、結果の一覧を表示します。演出を残して音だけ止める場合はサウンドをOFFにします。
  • ゲーム側の音量設定や他のアドオンとの表示の重なりは、実機で確認が必要です。

ここで紹介する効果・使い方はゲーム内の設定です。現実のキノコの食用判断には使えません。
