Mycology / 小さな機能

鑑定結果の開封演出

キノコを順に紹介し、最後に最高レアを発表。

コード上の設定を確認 / ゲーム内動作は未確認

どんなもの？

鑑定したキノコの一部を順番に紹介してから、今回の最高レアを発表する演出です。種類ごとに音色とメロディが設定されています。すべての結果は最後の鑑定内訳で確認できます。

使い方

演出中にしゃがむと結果画面へスキップする設定です。

入手方法・利用条件

Mycologyの鑑定士メニューで利用する機能です。鑑定士の所在は公開案内を準備中です。

確認できた設定

以下はコードに設定された値です。本番の効果・表示を検証した結果ではありません。

  • 64個の通常演出は20 TPS時に15〜25秒、短縮では約3.3〜5.5秒です。サーバーが重い場合は長くなることがあります。
  • アイテムの受け渡しと発見記録は演出の前に処理されます。演出を飛ばしても再抽選する仕組みではありません。
  • 最高レア以外に紹介するのは最大4種類。実際の結果より高いレア度を予告しない構成です。
  • 最新演出の音量・見え方・端末での操作は実機未確認です。

ここで紹介する効果・使い方はゲーム内の設定です。現実のキノコの食用判断には使えません。
