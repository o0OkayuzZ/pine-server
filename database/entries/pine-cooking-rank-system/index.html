Pine Cooking / 小さな機能

料理Rankとナイフ制限

料理をRankで分類し、ナイフ素材ごとに作成可能な上限を設定。

コード上の設定を確認 / ゲーム内動作は未確認

どんなもの？

料理UIは素材とRank I〜VIIに分かれています。現在の料理はRank II〜VIを中心に配置され、使用中のナイフで作れないRankはロック表示されます。

使い方

左側のRankタブを選び、中央の料理アイコンから作りたい料理を選択します。

入手方法・利用条件

ナイフ素材を上位へ更新すると、より高いRankの料理を作れるようになります。

確認できた設定

以下はコードに設定された値です。本番の効果・表示を検証した結果ではありません。

  • 銅：Rank IIまで / 鉄：Rank IIIまで / 金：Rank IVまで。
  • ダイヤモンド：Rank VIまで / ネザライト：Rank VIIまで。
  • Rank IとVIIは将来拡張用の空き区分です。
