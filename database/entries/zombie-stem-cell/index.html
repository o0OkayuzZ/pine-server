Zombie Gear / アイテム・ブロック

ゾンビ幹細胞

防具の作成と、8秒チャージによる浄化に使う素材。

コード上の設定を確認 / ゲーム内動作は未確認

どんなもの？

腐敗を1段階浄化し、残機を1つ補充するための素材です。C0では残機の補充に使えます。

使い方

4部位を装備し、手に持って8秒しゃがみます。

入手方法・利用条件

作業台で不死のトーテム4個と腐った肉5個から1個作成します。

  • ゾンビ幹細胞の作り方 →

確認できた設定

以下はコードに設定された値です。本番の効果・表示を検証した結果ではありません。

  • 浄化できる腐敗度があれば、現在の残機上限でも使用できます。
  • 成功時に1個消費。C4/残機0からC3/残機1へ戻せます。
  • C0で残機4の場合は使用しません。
