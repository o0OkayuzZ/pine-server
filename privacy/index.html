アクセス計測・AIについて

PINE SERVERのページを、より探しやすくするために。

現在の計測状態

設定された計測サービスを使用しています。

Cloudflare Web Analyticsによる基本集計

ページを開いた際に、Cookieやローカルストレージを使わないCloudflare Web Analyticsでページ閲覧や表示性能を集計します。下のGoogle Analyticsの許可・拒否とは別に動作します。詳しい図鑑操作の分析はGoogle Analyticsへの許可がある場合に限ります。

Cloudflare Web Analyticsの説明

Google Analytics 4の利用

ページ上で「許可する」を選んだ場合に、Google Analyticsの読み込みとアクセス計測を開始します。「許可しない」を選んでも、サイトの機能は利用できます。設定はページ下部の「アクセス計測の設定」から変更できます。

閲覧したページ、端末やブラウザ、流入元、図鑑の検索使用・絞り込み・一覧展開、アイテムやレシピの閲覧、参加案内へのクリックなどを集計します。スクロール、外部リンクのクリック、対応する埋め込み動画の再生、ファイルのダウンロードリンクのクリックも集計します。これらにはリンク先URL・ファイル名・動画情報が含まれます。サイトの独自計測で送るページURLには検索条件やページ内リンクを含めず、検索入力の文章・氏名・メールアドレスを送る独自の計測は行いません。

Google AnalyticsはCookieを使用します。広告向け機能とGoogleシグナルは、このサイトの計測コードでは無効にしています。集計結果は運営者が本人用の管理画面で確認し、公開図鑑には表示しません。

Googleによるサイト利用情報の取り扱い

ピネ鯖案内AI「拓也」

拓也へ送った質問文と、同じブラウザタブ内の直近の会話は、回答を作るためにPINE SERVERのAI用APIを経由してOpenAI APIへ送信されます。OpenAI APIへのリクエストではResponsesの通常の応答保存を無効にする設定を使用します。OpenAI APIへ送信されたデータは、明示的にオプトインしない限りモデル学習には使用されません。一方、標準設定では不正利用監視のためプロンプトや応答を含むログが最大30日保持される場合があります。質問には氏名、連絡先、パスワード、認証情報などの個人情報・秘密情報を入力しないでください。

拓也は公開中のピネWeb情報を検索して回答します。未確認の仕様や計画中の内容を実装済みとして断定しないよう制御していますが、AIの回答には誤りが含まれる可能性があります。重要な仕様は回答に表示される関連ページも確認してください。

OpenAI APIのデータ管理について

集計で分からないこと

Google Analyticsの集計には、許可しなかったアクセスは含まれません。Cloudflareも含め、ブラウザのブロック・通信失敗などで計測できない訪問があります。全訪問者を100%記録するものではありません。計測開始前の訪問は復元できず、誰が訪問したかを氏名の一覧で確認する仕組みではありません。
